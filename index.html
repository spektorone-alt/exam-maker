מעלים מאגר PDF של מבחנים קיימים → המערכת מפרקת לשאלות בודדות → בוחרים כמות → מקבלים מבחן חדש אקראי, עם המבנה המקורי בדיוק

1 העלאת מאגר מבחנים (PDF)

📄 גררו לכאן קבצי PDF, או לחצו לבחירה (אפשר לבחור כמה קבצים יחד)

⚙️ הגדרות חיבור ל-Google Drive

כדי לייבא ישירות מ-Drive צריך OAuth Client ID + API Key מ-Google Cloud Console (פרויקט אישי שלכם):
1. ב-Google Cloud Console: הפעילו את Google Drive API ואת Google Picker API.
2. צרו OAuth 2.0 Client ID מסוג "Web application", והוסיפו כ-Authorized JavaScript origin את הכתובת שבה מתארחת האפליקציה הזו (למשל דף ב-GitHub Pages שלכם).
3. צרו גם API Key (Credentials → Create → API key), והגבילו אותו ל-Picker API.

עדיין לא הועלו שאלות. העלו קבצי PDF למעלה.

3 הרכבת מבחן חדש

שימו לב: כל שאלה נשמרת ומועתקת כעמוד PDF מקורי (לא כתמונה) — כך שרטוטי המעגלים, הנוסחאות והפורמט נשמרים במדויק. מספרי השאלות בגוף המסמך נשארים כפי שהיו במבחן המקור; טבלת הניקוד הכוללת בעמוד השער אינה מתעדכנת אוטומטית לפי הבחירה החדשה. הבנק נשמר אוטומטית בדפדפן שלכם (אישי, לא משותף) כך שבפעם הבאה שתפתחו את האפליקציה הוא עדיין יהיה כאן.
